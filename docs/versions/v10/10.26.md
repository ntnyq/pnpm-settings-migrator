# pnpm 10.26

Compared with pnpm 10.25.x. Patch changes within 10.26.x are listed at their exact release boundaries.

## Changed fields

`allowBuilds` becomes available at 10.26.0. With `--replace-deprecated`, the
migrator can replace legacy build permissions with this setting. At 10.25.x,
older releases, or unconfirmed v10 targets, it retains the legacy setting names
and reports a warning. This does not change the default `replaceDeprecated: false`.

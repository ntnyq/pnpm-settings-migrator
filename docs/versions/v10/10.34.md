# pnpm 10.34

Comparison baseline: pnpm 10.33.x. Existing records do not establish the complete
10.33 → 10.34 field delta; the confirmed 10.34 patch boundaries below are retained
from the audits. Missing history is not evidence of no changes.

## Recorded patch changes

From 10.34.5, project workspace proxy fields (`httpProxy`, `httpsProxy`,
`noProxy`, `proxy`, and `noproxy`) do not expand `${...}` placeholders. The
migrator retains dynamic proxy values in their sources for every target and
rejects existing dynamic workspace proxies before writes. Use trusted global
configuration or environment variables; the migrator never expands these values.

The subsequent audits through 10.34.9 record no additional project-setting
migration rule. Real 10.34.9 CLI, install, and frozen-install checks cover plain
and wildcard override cases; the complete migration harness covers v11/v12.

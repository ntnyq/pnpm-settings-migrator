# pnpm 11.22

Compared with pnpm 11.21.x. Patch changes within 11.22.x are listed at their exact release boundaries.

## Added fields

- `minimumReleaseAgeExcludePrune`.

## Project scope changes

`bin`, `configDir`, `dir`, `globalBinDir`, `globalDir`, `npmrcAuthFile`,
`pnpmHomeDir`, `stateDir`, `userconfig`, and `workspaceDir` are refused in
project workspace settings. They stay in their source with diagnostics.
`cacheDir` and `storeDir` retain their existing scope.

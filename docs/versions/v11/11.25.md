# pnpm 11.25

Compared with pnpm 11.24.x. Patch changes within 11.25.x are listed at their exact release boundaries.

## Added and changed fields

- `audit.ignorePrune`.
- `tasks`, including task `concurrency` and dependency graph settings.
- `remoteSideEffectsCache` and structured `sideEffectsCache: { read, write, remote }`.
  Legacy booleans, `sideEffectsCacheReadonly`, remote-cache and `organization`
  forms remain readable; newer forms take precedence.
- Project workspace `scope` is ignored. Use CLI, environment, or global config;
  the migrator retains project source values with diagnostics.

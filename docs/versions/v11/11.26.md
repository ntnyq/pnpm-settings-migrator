Compared with pnpm 11.25.x. Patch changes within 11.26.x are listed at their exact release boundaries.

## Field differences

The recorded 11.25.0 → 11.26.0 comparison found no added workspace fields or
config-reader type changes. New trust-policy CLI flags use existing settings.

`scriptShell` relative paths resolve from the workspace root, and CLI overrides
of `sideEffectsCache` preserve remote configuration. Keep explicit values;
no setting rename or generated default is needed.

# pnpm 11.29 settings

Compared [v11.28.13 with v11.29.0](https://github.com/pnpm/pnpm/compare/v11.28.13...v11.29.0).
11.28.13 is the last published 11.28 release in the November 24 registry
snapshot. See the [11.28 notes](11.28.md) for earlier patch boundaries and the
[November 24 audit](../../research/pnpm-settings-bump-2026-11-24.md) for executed checks.

| Setting or scope                          | Change in 11.29.0                                                                                                                                                                                                                                                      | Migrator behavior                                                                                                                                   |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `otp`                                     | Workspace and global files ignore it and report the per-run alternatives, `--otp` and `PNPM_CONFIG_OTP`.                                                                                                                                                               | Reports it as refused in a manifest and rejects it in existing workspace YAML before writes. Continues preserving authentication lines in `.npmrc`. |
| `noProxy`, `strictSsl`, `localAddress`    | The workspace and global readers validate types. The accepted values are string or boolean, boolean, and string, respectively. An explicit null leaves the setting unset.                                                                                              | Keeps invalid incoming settings in their original sources. Preserves valid values and nulls.                                                        |
| `minimumReleaseAge`                       | The install policy requires a finite non-negative number of minutes, including fractional values. The reader normalizes numeric strings to numbers and a scalar exclusion to a list. Blank numeric environment overrides leave lower-priority configuration effective. | Rejects invalid literal ages at the new boundary and retains numeric source text and environment placeholders.                                      |
| `sideEffectsCache.exclude`                | The reader validates an optional array of strings. The v11 cache application still uses the read, write, and remote options.                                                                                                                                           | Keeps the complete cache object in its source when it contains an exclusion.                                                                        |
| `tasks.<name>`                            | A null entry produces a validation error with guidance to use an empty map for an explicitly configured task.                                                                                                                                                          | Retains the whole incoming task section, or rejects existing YAML before writes.                                                                    |
| `referenceTime`                           | The reader names the newer major in its warning.                                                                                                                                                                                                                       | Retains the value for v11 targets.                                                                                                                  |
| Global commands and temporary executables | Global commands skip the current project's files and hook. Temporary executable commands skip local hooks and project proxy or TLS settings while inheriting selected resolution settings.                                                                             | Continues moving supported project settings for project commands and keeping project credentials and TLS material in their sources.                 |

Missing YAML environment variables now produce a named configuration error.
The release changes TLS path resolution, protected configuration display, and
registry credential forwarding. It also applies existing install policies in
more lockfile and pnpr paths. The migrator preserves the existing field names
and values for those policies. [Release notes](https://github.com/pnpm/pnpm/releases/tag/v11.29.0),
[workspace validation](https://github.com/pnpm/pnpm/blob/v11.29.0/pnpm11/config/reader/src/getOptionsFromRootManifest.ts),
[proxy validation](https://github.com/pnpm/pnpm/blob/v11.29.0/pnpm11/config/reader/src/proxySettings.ts),
[release-age policy](https://github.com/pnpm/pnpm/blob/v11.29.0/pnpm11/config/version-policy/src/index.ts).

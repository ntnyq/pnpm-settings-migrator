# pnpm 12.3

Compared with pnpm 12.2.x. Patch changes within 12.3.x are listed at their exact release boundaries.

## Field differences

The recorded 12.2.1 → 12.3.4 source comparison found no changes to known settings,
workspace field declarations, config types, or refused fields.

From 12.3.0, an explicit `minimumReleaseAge` makes `minimumReleaseAgeStrict`
default to true; the built-in 1440-minute default stays non-strict. Preserve
explicit values without inserting configuration to reproduce the earlier bug.

12.3.1–12.3.4 contain no recorded field renames or removals. Dynamic proxy
placeholders are ignored in project YAML; the migrator retains them in source.

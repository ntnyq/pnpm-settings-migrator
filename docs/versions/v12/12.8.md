# pnpm 12.8

Compared with pnpm 12.7.x. Patch changes within 12.8.x are listed at their exact release boundaries.

## 12.8.0–12.8.1

No additional project fields were found in the recorded comparison with 12.7.0.
The fixes affect CLI precedence, environment handling, installs, and deduplication.

## 12.8.2

`globalShims` is restricted to trusted global configuration. Incoming values stay
in their sources with an incompatibility warning; existing workspace values
fail validation before writes. Earlier v12 releases retain their previous behavior.

`childConcurrency` defaults to 5 after an upstream correction. The migrator moves
explicit values and does not insert this default.

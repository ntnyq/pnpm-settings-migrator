# pnpm 12.1

Compared with pnpm 12.0.x. Patch changes within 12.1.x are listed at their exact release boundaries.

## Added and changed fields

- `tasks` and structured `sideEffectsCache` are shared with v11.25.
- `scope` is ignored in project workspace YAML and must come from CLI,
  environment, or trusted global configuration.

No separate copy of the shared schema or speculative key conversion is needed.

# pnpm 12.2

Compared with pnpm 12.1.x. Patch changes within 12.2.x are listed at their exact release boundaries.

## Field differences

The existing audit records no new setting conversion. Catalog resolution adds
`workspace:` support, while install stops leaking global `minimumReleaseAgeExclude`
into the workspace. `globalDir` and `globalBinDir` remain machine-level settings.
Object-form `sideEffectsCache` and CLI-override fixes preserve existing values.

12.2.1 fixes a POSIX self-upgrade executable target and adds no setting delta.

# pnpm 12.23 settings

Compared [v12.22.0 with v12.23.0](https://github.com/pnpm/pnpm/compare/v12.22.0...v12.23.0).
12.22.0 is the last published 12.22 release in the November 24 registry
snapshot. See the [November 24 audit](../../research/pnpm-settings-bump-2026-11-24.md)
for verification and the release comparison.

| Setting or scope                    | Change in 12.23.0                                                                                                                                                                                                                                                                                                                                                                                          | Migrator behavior                                                                                                                                                                                                        |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `nodeLinker`                        | Adds objects for `isolated`, `hoisted`, and `pnp`. Isolated accepts `hoist` as a boolean or a map with optional `public` and `private` pattern arrays. Hoisted accepts `hoistingLimits` as `none`, `workspaces`, or `dependencies`. Nested options take precedence over corresponding flat settings in the same layer.                                                                                     | Enables the new objects on confirmed 12.23+ targets, keeps supported flat fields as written, and preserves existing loaded linker support from 12.10. Merge strategies combine options only within the same linker type. |
| `referenceTime`                     | A workspace RFC 3339 timestamp sets the clock for `minimumReleaseAge` and `trustPolicyIgnoreAfter` during resolution and lockfile verification. Unset uses the current time. `PNPM_CONFIG_REFERENCE_TIME` overrides YAML. The global file drops the field. The workspace reader rejects a time more than ten minutes ahead and validates the timestamp before substituting ordinary environment variables. | Accepts a literal timestamp or null on confirmed 12.23+ targets. Retains invalid or dynamic values.                                                                                                                      |
| `versioning.includePrivatePackages` | Optional boolean, defaulting to true. False excludes private projects from `pnpm change`. Release planning and lanes still include them.                                                                                                                                                                                                                                                                   | Validates the section on confirmed 12.23+ targets. On earlier or unconfirmed targets, retains any versioning object containing the new key.                                                                              |
| `warnUnusedOverrides`               | Boolean, defaulting to true. Reports unused workspace overrides, excluding overrides supplied by a config dependency or hook.                                                                                                                                                                                                                                                                              | Migrates explicit valid values, including false, on confirmed 12.23+ targets.                                                                                                                                            |
| `access` and `tag`                  | Publish reads both from workspace YAML, global config, and environment. Publish flags win. Configured `access` wins over `publishConfig.access`. Workspace `access` passes through as a string, while the dedicated environment setting accepts `public` or `restricted`. Existing `tag` support now applies to publish.                                                                                   | Enables the workspace string or null for `access` at 12.23. Keeps the existing 12.16 boundary for `tag`.                                                                                                                 |
| `editor`                            | An editor command belongs to trusted configuration or a per-run flag. Project YAML accepts an explicit null to clear the inherited value.                                                                                                                                                                                                                                                                  | Allows project null starting in 12.23 and refuses project commands.                                                                                                                                                      |
| `otp` and `noProxy`                 | Config files ignore `otp`, which becomes per-run only. `noProxy` validates strings and booleans, with null leaving it unset.                                                                                                                                                                                                                                                                               | Reports manifest OTP as refused, preserves the existing `.npmrc` auth handling, and retains invalid proxy bypass values in their sources.                                                                                |
| Global and temporary commands       | Global package commands skip project files, apply the global packages auth configuration, and consume the top-level global build policy. `PNPM_CONFIG_HOME` selects the machine configuration directory. Temporary executable commands retain an allowlist of resolution settings from the project and use trusted configuration for execution, layout, and networking.                                    | Keeps machine settings out of workspace output. Existing project keys remain portable for project commands.                                                                                                              |

pnpm removes package platform variants and their pack and publish flags. This
affects publication manifests and lockfiles. The release also changes npm
registry and TLS handling, the cache identity used with `nodeVersion`, matching
of already-supported peer rules, empty publish branch behavior, and enforcement
of existing install policies. These changes require no setting rewrite.
[Release notes](https://github.com/pnpm/pnpm/releases/tag/v12.23.0),
[linker reader](https://github.com/pnpm/pnpm/blob/v12.23.0/pnpm/crates/config/src/node_linker.rs),
[workspace fields](https://github.com/pnpm/pnpm/blob/v12.23.0/pnpm/crates/config/src/workspace_yaml/settings.rs),
[workspace validation](https://github.com/pnpm/pnpm/blob/v12.23.0/pnpm/crates/config/src/workspace_yaml/validation.rs),
[versioning shape](https://github.com/pnpm/pnpm/blob/v12.23.0/pnpm/crates/versioning/src/settings.rs).

For example, a `package.json#pnpm` setting of
`"nodeLinker": { "type": "isolated", "hoist": false }` migrates as follows
when the resolved target is 12.23.0.

```yaml
nodeLinker:
  type: isolated
  hoist: false
```

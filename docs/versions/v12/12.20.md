# pnpm 12.20

Compared exact tags **12.19.0 → 12.20.0**, including the full configuration
source diff and release notes. No new, removed, renamed, or deprecated workspace
fields or nested configuration value shapes were found. No new migration
capability is needed; the 12.19 settings retain their exact introduction boundary.

## Consumption changes

With `lockfile.format: v13`, **12.20.0** starts recording the dependency
specifiers of local directory packages. Frozen installation rejects edits to
those specifiers even when the locked dependency version still satisfies the new
range. This affects generated lockfile behavior, not migration of the `format`
option. The real-release fixture compares 12.19.0 and 12.20.0, unchanged frozen
installs, a changed local dependency range, and regenerated lockfiles.

Range-scoped overrides now dereference `catalog:` entries when matching, and
`workspace:` path overrides also apply to transitive registry packages. Existing
selector/value representations are preserved without a new transformation.
Peer resolution, hoisted linking and deployment fixes similarly change
consumption rather than accepted setting shapes.

Remote resolution, shared build caches and release notes require a pnpr server
newer than 0.1.0-alpha.19 with advertised protocol capabilities. Registry
declarations and cache settings keep their existing shapes. The migrator does
not rewrite server versions or synthesize protocol settings. New CI environment
detection and the bundled node-gyp update do not require source-setting changes.
